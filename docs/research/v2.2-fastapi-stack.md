# V2.2 Research & Infra Plan: Zero-Budget Python FastAPI Stack

**Objective:** Define a $0, strictly **NO CREDIT CARD REQUIRED** infrastructure stack for V2.2 (panel-authored blogs + case studies + media) using a Python FastAPI backend.

This document builds upon previous research (`v2.2-cms-db-research.md` and `v2.2-cloudflare-migration-plan.md`) but pivots the backend execution environment to Python FastAPI while retaining the zero-cost, no-card constraint.

---

## 1. Python FastAPI Hosting (The Backend)

To host a Python FastAPI app without a credit card and without incurring charges, we evaluated several platforms:

| Platform | Free Tier Limits | Cold Start / Pause | Credit Card Required? | Verdict |
|----------|-----------------|--------------------|-----------------------|---------|
| **Vercel (Serverless Python)** | 100k requests/day (Hobby) | ~1–3s cold start (scale-to-zero) | **No** | **Recommended.** Excellent developer experience, fast cold starts, no CC required. |
| **Render (Web Service)** | 750 hours/mo | Sleeps after 15m idle. 30s-1m cold start. | **No** | Fallback. The 15-minute sleep means the first admin click takes ~1 minute to load. |
| **Fly.io** | Generous compute | N/A | **Yes** (required for signup) | ❌ Rejected (Requires CC) |
| **Koyeb** | Generous compute | N/A | **Yes** (required for signup) | ❌ Rejected (Requires CC) |
| **HF Spaces** | 16GB RAM, 2vCPU | Sleeps after 48h idle | **No** | Intended for ML, not standard web APIs. |

**Recommendation: Vercel Python Serverless (Hobby Plan).**
It integrates perfectly with FastAPI, has no 15-minute hard sleep (just standard serverless cold starts of a couple of seconds), and strictly requires no credit card. Since this API is primarily for admin writes (with public read pages being statically generated or heavily cached), serverless is the optimal model.

## 2. Database (The Data Store)

We need a database compatible with Python/FastAPI that doesn't hard-pause (like Supabase's 7-day inactivity pause) and requires no credit card.

| Platform | Engine | Free Tier Limits | Credit Card Required? | Verdict |
|----------|--------|-----------------|-----------------------|---------|
| **Turso** | libSQL (SQLite) | 9 GB storage, 1B reads/mo | **No** | **Recommended.** Massive storage limit, edge-ready, no pausing, fast HTTP API. |
| **Neon** | Serverless Postgres | 500 MB storage, compute scales to zero | **No** | Alternative. Autosuspend after 5m, wakes in ~1s. 500MB is enough for text. |
| **Supabase** | Postgres | 500 MB storage | No | ❌ Rejected (7-day hard pause kills portfolios) |

**Recommendation: Turso.** 
It provides a massive 9 GB free tier for SQLite, requires no credit card, and never suspends your database. It connects natively via the Python `libsql-client`. 

---

## 3. Media Storage (The CDN)

As previously validated, **Cloudinary** remains the undisputed choice for media.
- **Cost/Card:** 100% Free (25 credits/month = ~25GB storage/bandwidth). **NO credit card required.**
- **Architecture:** The FastAPI backend will generate a signed payload using the `cloudinary` Python SDK, allowing the frontend admin panel to upload images directly to Cloudinary without routing heavy files through the serverless function.

---

## 4. Admin Authentication

Since Cloudflare Zero Trust requires a credit card, we will handle auth within the FastAPI app itself.
- **Implementation:** FastAPI will implement a simple JWT auth endpoint. The admin password hash is stored in a Vercel Environment Variable (`ADMIN_PASSWORD_HASH`).
- **Flow:** The React admin panel sends a login request to FastAPI. FastAPI verifies the hash and returns a signed JWT (using a `JWT_SECRET`). Subsequent write requests to FastAPI include this JWT.
- **Cost/Card:** 100% Free.

## 5. Frontend Static Hosting

- **Option A: GitHub Pages.** Stays exactly as is. The React app simply sets its `API_BASE_URL` to the Vercel FastAPI URL.
- **Option B: Cloudflare Pages.** Migrate the React app to CF Pages for faster global CDN.
- **Recommendation:** Stick with **GitHub Pages** for now to minimize moving parts, unless faster global deployment is desired. Both are $0 and require no card.

## 6. Deploy Pipeline

1. **Frontend:** Continues using GitHub Actions for visual tests, perf checks, and deployment to GitHub Pages.
2. **Backend:** Vercel automatically deploys the FastAPI app on pushes to the repository (e.g., if backend is in an `api/` directory, Vercel picks it up via `vercel.json`).

## 8. Human-Setup Checklist (NO CREDIT CARD REQUIRED)

1. **Create Vercel Account:** Sign up for a free Vercel Hobby account (GitHub login).
2. **Create Turso Account:** Sign up for a free Turso account and create a database.
3. **Create Cloudinary Account:** Sign up for a free Cloudinary account.
4. **Environment Secrets:** In the Vercel dashboard, add the following secrets:
   - `TURSO_DATABASE_URL` and `TURSO_AUTH_TOKEN`
   - `CLOUDINARY_API_KEY` and `CLOUDINARY_API_SECRET`
   - `ADMIN_PASSWORD_HASH` (your SHA-256 hashed password)
   - `JWT_SECRET` (a random string for signing admin sessions)
